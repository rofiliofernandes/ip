# UI Changes

The homepage now follows the approved visual mockup closely: compact cinematic hero, three-photo strip, editorial About section, 4x2 Gallery, 4x4 Instagram image gallery, 4-column YouTube gallery, testimonials, 8-column Instagram Reels, and dark footer.

Instagram image posts and Instagram Reels are deliberately separate data streams. New Instagram image posts appear first in the 16-image grid after they are imported and approved.

Navigation keeps the hamburger menu and dark/light mode. Public naming uses Gallery rather than Projects and no year selector is shown.
