# V4 Implementation

Implemented the V4 visual fixes on top of the V3 project:

- Improved admin light-mode contrast for headings, names, emails, roles, labels, muted/helper text, cards, inputs, counters and navigation.
- Improved theme-toggle reliability and accessibility with explicit state and focus styling.
- Increased the public header logo slightly while keeping it proportional and readable.
- Positioned the public header logo against the true left side of the header rather than a centered content wrapper.
- Preserved theme-aware logo treatment: original logo in light mode and white logo in dark mode.
- Replaced the native Careers salary checkbox with a custom animated disclosure toggle that remains keyboard accessible and works in both themes.
- Added mobile sizing adjustments for the header logo and salary control.

This package contains the V3 project plus only the requested V4 changes.
